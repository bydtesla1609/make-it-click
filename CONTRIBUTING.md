# Contributing

Make It Click keeps one public expression library at [`skill/make-it-click/references/expression-library.md`](skill/make-it-click/references/expression-library.md). Contributions may add an explanation method, add a selection framework, or improve an existing entry.

Before submitting:

1. Check for an equivalent entry; improve it instead of duplicating it.
2. Follow the entry contract and candidate format in [`contributing.md`](skill/make-it-click/references/contributing.md).
3. Generalize the technique and remove private conversation details.
4. Confirm that the example, return path, and accuracy boundary agree with the method.
5. Run the validation commands in the README and review the applicable behavior cases.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
